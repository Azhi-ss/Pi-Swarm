# Pi-Swarm

A decentralized, self-organizing multi-agent swarm system where peer-equal coding agents independently explore solution hypotheses in isolated sandboxes, with objective machine verification as the sole arbiter of correctness.

## Language

### Topology & Roles

**Peer Node**:
An agent instance in the swarm mesh. All peers have identical privileges — no master, no coordinator.
_Avoid_: Worker, slave, subordinate, child agent

**Delegator**:
The primary coding agent facing the human developer. Publishes goal specifications to the Blackboard and observes progress, but never micromanages peer execution.
_Avoid_: Orchestrator, coordinator, master agent

**Flat Mesh**:
The network topology connecting all peer nodes. No hierarchy, no hub-and-spoke — every node can read the Blackboard, stake hypotheses, and submit verified results.
_Avoid_: Star topology, master-slave, parent-child tree

### Blackboard & State Machine

**Blackboard**:
The single shared state surface for the entire swarm. Internally stored as an append-only JSONL event stream (write side) with a projected read-only Markdown snapshot `BLACKBOARD.md` kept under 1000 tokens (read side).
_Avoid_: Shared memory, message queue, database

**Goal Zone** _(Zone 1)_:
The section of the Blackboard holding task specifications, acceptance criteria, and dependency links.
_Avoid_: Backlog, task list

**Soft Staking Zone** _(Zone 2)_:
The section where peers declare which hypothesis they intend to explore, protected by a time-limited Lease.
_Avoid_: Assignment, hard lock, claim queue

**Verified Zone** _(Zone 3)_:
The section holding results that passed the Ground Truth Verifier — immutable golden facts with associated patch artifacts.
_Avoid_: Done pile, completed list

**Graveyard** _(Zone 4)_:
The section holding hypotheses that were machine-disproved. Contains error logs, counterexample tests, and the reason for failure. Prevents the swarm from repeating the same mistake.
_Avoid_: Trash, archive, dead letter queue

**Lease**:
A time-limited claim on a task in the Soft Staking Zone. Default TTL is 300 seconds. Extended by heartbeats; expires silently if the peer crashes, allowing lock-free preemption by other peers.
_Avoid_: Lock, mutex, assignment

**Heartbeat**:
A periodic signal from a peer extending its Lease. Absence of heartbeats after Lease expiry is interpreted as a crash.
_Avoid_: Ping, keepalive, health check

### Verification & Pruning

**Ground Truth Verifier**:
The verification gate intercepting `task.done`. Physically executes a test command in the peer's Sandbox; the machine exit code is the sole arbiter. Exit 0 = pass. Anything else = fail.
_Avoid_: Reviewer, judge, evaluator, self-assessment

**Steer Injection**:
The mechanism that sends real stderr/stdout from a failed verification back to the originating peer via Pi's `deliverAs: 'steer', triggerTurn: true` channel, forcing a self-healing retry in the Sandbox.
_Avoid_: Error notification, feedback message

**Fast Pruning**:
Automatic escalation after 3 consecutive verification failures on the same task. The hypothesis is marked `dead_end`, archived to the Graveyard, and a `task.dead_end` event is broadcast swarm-wide to prevent other peers from wasting compute on the same path.
_Avoid_: Retry limit, timeout, circuit breaker (that's a different concept)

**Patch Artifact**:
A `.patch` file generated by `git diff HEAD` in the Sandbox after successful verification. Stored at `.pi/messenger/artifacts/<taskId>.patch` and referenced in the Verified Zone.
_Avoid_: Diff, changeset, PR

### Sandbox & Isolation

**Sandbox**:
A physically isolated working directory for a single peer, created at `.swarm/workspaces/worker-<agentId>/` via `git worktree add --detach`. Shares the host's `.git/objects` but has its own file tree.
_Avoid_: Branch, fork, container, VM

**Detached HEAD**:
The Git checkout mode used for Sandboxes. No named branch is created — `git branch` on the host remains perfectly clean.
_Avoid_: Feature branch, temp branch

**Port Slot**:
A dynamically assigned `PORT` / `TEST_PORT` pair (offset by agent slot index) injected into the Sandbox environment, preventing `EADDRINUSE` conflicts during concurrent test runs.
_Avoid_: Port allocation, port pool

### Watchdog & Safety

**Watchdog**:
The physical process supervisor. Registers each peer as a managed background process with a hard timeout (default 600s). Handles zombie cleanup, stale Lease reclamation, and All-Dead detection.
_Avoid_: Monitor, supervisor daemon, health checker

**All-Dead Fallback**:
The safety protocol triggered when every hypothesis for a task has reached `dead_end` and no live peers remain. The Watchdog generates a structured failure brief and Steer-injects it to the Delegator, preventing silent deadlock.
_Avoid_: Timeout, circuit breaker, escalation

**Failure Brief**:
A structured summary (≤1500 tokens) of all failed hypotheses, their error stacks, and counterexamples. Delivered to the Delegator during an All-Dead Fallback.
_Avoid_: Error report, post-mortem, incident report

**Circuit Breaker**:
A global step-count budget (default 50 tool invocations across the entire swarm). When the budget is exhausted, the breaker fires `swarm.abort`, kills all peers, and locks the Blackboard to preserve any verified results.
_Avoid_: Rate limiter, throttle, quota (it's a hard stop, not a slowdown)

### Merge & Delivery

**Direct Verified Merge**:
The automated protocol where a peer that passes the Ground Truth Verifier has its patch atomically applied and committed directly to the host's `main` branch.
_Avoid_: Pull request, code review, manual merge

**Rebase-on-Conflict**:
The deterministic conflict resolution protocol where a peer whose patch collides with the evolving `main` branch is mechanically bounced back into its Sandbox to rebase onto latest HEAD and re-verify, rather than debating conflicts in natural language.
_Avoid_: Merge conflict discussion, manual merge resolution

### Observation & Control

**Context Admission**:
The protocol and mental model injected into the Delegator, enabling it to ingest `BLACKBOARD.md` on demand and explain swarm status to the human without hallucinations or micromanagement.
_Avoid_: System prompt injection, agent instruction

**Observer Commands**:
The three canonical human-facing control commands: `status` (compact four-zone ANSI card), `explain` (intelligent Delegator situation brief), and `abort` (instant physical emergency brake via `SIG_ABORT`).
_Avoid_: Dashboard, monitoring suite, control panel
