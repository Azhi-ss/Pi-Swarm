# Cohort peers cooperate by message, not by assigned tasks

A Cohort is N identical Peer Nodes started after the Delegator asks for a Launch Tier. They share one problem statement. The Delegator is not a member, does not assign roles or hypotheses, and afterward only reads the Blackboard back to the human.

Peers cooperate by Peer Message, which is inserted into the recipient's context, at any time. The launch does not create tasks, so Soft Staking, Leases, and the Ground Truth Verifier do not divide a Cohort. Those remain for runs that do create tasks.

This rejects a coordinator that hands work to children and waits for answers. That scaffold cannot let two peers with the same problem talk, and it forces a peer who is unsure to guess or stop and ask the parent. The cost is that a Cohort has no task-shaped pruning or verification until a peer's result is otherwise recorded on the Blackboard.
